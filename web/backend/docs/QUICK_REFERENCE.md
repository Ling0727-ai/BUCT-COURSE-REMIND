# 🎯 功能改进快速参考

## ✨ 新增功能

### 1️⃣ 忘记密码邮件包含用户名

**问题:** 用户忘记密码时也经常忘记用户名  
**解决:** 验证码邮件中自动显示用户名  
**位置:** 忘记密码 → 输入邮箱 → 收到邮件/看到提示

### 2️⃣ 支持用户名或邮箱登录

**问题:** 只能用用户名登录，不方便  
**解决:** 现在可以用用户名或邮箱登录  
**示例:**

- ✅ `zhangsan` + 密码
- ✅ `zhangsan@example.com` + 密码

## 🚀 快速使用

### 场景1: 忘记密码和用户名

```
1. 点击"忘记密码"
2. 输入邮箱
3. 获取验证码
4. 👀 查看邮件或页面提示，获得用户名
5. 重置密码
6. 用用户名或邮箱登录
```

### 场景2: 记得邮箱但不记得用户名

```
1. 直接用邮箱登录
2. 输入密码
3. 登录成功！
```

## 📋 修改的文件

### 后端

- `app/auth.py`
    - `login()` - 支持邮箱登录
    - `send_verification_email_enhanced()` - 包含用户名
    - `send_verification_code()` - 查找用户名

### 前端

- `src/views/Login.vue` - 输入框改为"用户名/邮箱"
- `src/components/ForgotPasswordModal.vue` - 显示用户名提示

## 📞 遇到问题？

**测试邮件发送:**

```bash
cd web/backend
python test_email_sending.py
```

**查看日志:**

```bash
tail -f logs/app.log | grep "登录\|验证码"
```

**常见错误:**

- "账号不存在" → 检查用户名/邮箱拼写
- "密码错误" → 检查密码
- "邮件服务不可用" → 检查 `.env` 中的 `MAIL_PASSWORD`
