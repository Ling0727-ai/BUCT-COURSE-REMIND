# 用户登录和密码找回功能改进说明

## 改进内容

### 1. 忘记密码邮件包含用户名

**问题:** 用户忘记密码时，经常也会忘记用户名，导致重置密码后仍无法登录。

**解决方案:**

- 在发送验证码邮件时，自动包含该邮箱对应的用户名
- 邮件中会显示"您的用户名：XXX"，方便用户记忆
- 如果邮箱不存在用户，会提示联系管理员

**实现细节:**

1. 后端 `send-verification-code` API 查找邮箱对应的用户
2. 将用户名传递给邮件发送函数
3. 在HTML邮件中显示用户名信息
4. 测试模式下也会显示用户名

**邮件内容示例:**

```
验证码: 123456

您的用户名：zhangsan

有效期: 3分钟
```

### 2. 支持用户名或邮箱登录

**问题:** 用户只能使用用户名登录，如果忘记用户名就无法登录。

**解决方案:**

- 登录时支持输入用户名或邮箱
- 后端自动识别输入的是用户名还是邮箱
- 提供更友好的错误提示

**实现细节:**

1. 后端登录API先尝试用户名查找
2. 如果用户名未找到，尝试邮箱查找
3. 前端输入框提示改为"用户名/邮箱"
4. 错误提示更清晰："账号不存在，请检查用户名或邮箱"

**登录流程:**

```
输入: zhangsan 或 zhangsan@example.com
  ↓
后端尝试用户名查找
  ↓
如果未找到，尝试邮箱查找
  ↓
验证密码
  ↓
登录成功
```

用户可以直接看到用户名和验证码。

```python
# 发送邮件（包含用户名）
```

```python

user = mongo.db[USERS_COLLECTION].find_one({'username': username_or_email})
```

## 安全考虑

### 1. 用户名隐私

- 用户名仅在用户验证了邮箱所有权后显示
- 需要输入正确的验证码才能看到用户名
- 防止恶意查询用户名

### 2. 邮箱枚举攻击

- 发送验证码有频率限制（1分钟一次）
- 验证码有效期短（3分钟）
- 日志记录所有验证码发送请求

### 3. 登录安全

- 无论是用户名还是邮箱，密码验证逻辑相同
- 错误提示不透露账号是否存在
- 保持原有的登录安全机制
